主走查：一次调用

一次调用用四个环节串起全部主要组件。 每个环节只回答“谁接手、做什么、下一站是谁”。

  1. 触发：调用者通过 主程序入口 把输入交给 CLI。
  2. 分发：CLI 把工作导向 crawler，入口不承担全部核心职责。
  3. 协作：crawler 与 fetch 组合仓库内职责；外部依赖边界由 Cargo.toml 记录。
  4. 观察：系统把 命令结果 交回调用者；测试入口复核同一路径。
